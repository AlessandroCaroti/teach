# GLOSSARY.md Format

`GLOSSARY.md` is the canonical language for this exam, taken from the student's own materials rather than generic definitions. All lessons, quizzes, mock exams, and reference docs should use its terms consistently. Building it is itself a study technique: compressing a concept into a tight, accurate definition is evidence the student understands it.

## Structure

```md
# {Exam} Glossary

{One or two sentence description of the exam this glossary covers.}

## Terms

**Mitosis**:
Cell division producing two genetically identical daughter cells, used for growth and repair.
_Source_: Week 2 slides, slide 14
_Avoid_: "Normal cell division" (the materials never use this phrasing)

**Meiosis**:
Cell division producing four genetically distinct daughter cells with half the chromosome number, used in sexual reproduction.
_Source_: Week 2 slides, slide 18
```

## Rules

- **Add a term only once the student understands it**, not the moment it's introduced. The glossary records compressed knowledge, not a dictionary to learn from.
- **Use the materials' own definition and phrasing**, not a more familiar textbook version. The exam will use the course's language, and that's what needs to stick. Cite where each definition comes from.
- **Be opinionated when the materials are.** If a term shows up with several names, use whichever the materials actually use, and list the rest under `_Avoid_`.
- **Use the glossary's own terms inside later definitions.** Once a term is in here, prefer it everywhere, including inside other definitions.
- **Group under subheadings** when natural clusters emerge (e.g. `## Genetics`, `## Cell structure`). A flat list is fine when terms cohere.
- **Flag where the materials themselves are inconsistent.** If two slides define something slightly differently, note both and which one to rely on (or ask the student's instructor) rather than picking silently.
- **Revise as understanding deepens or new materials arrive.** Update in place; don't leave a stale or now-contradicted entry standing.
